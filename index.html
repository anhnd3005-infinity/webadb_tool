Cách 1: Chạy Local Node.js Server (Bằng Script tự động)

1. Máy tính cần cài sẵn Node.js và ADB (xem Bước 0 ở trên).
2. Tải script tự động khởi động (script sẽ tự tải file server.js):
👉 start_server.sh (Dành cho macOS / Linux)
👉 start_server.bat (Dành cho Windows)
3. Chạy script vừa tải về (Mac: Chạy lệnh sh start_server.sh trong Terminal; Windows: Double-click vào file .bat).
4. Nhập IP máy tính của bạn vào ô Local Server URL trên trình duyệt.
